# Shipped trusted keys

Public keys in this directory are trusted by every box built from this
repository. `PnetPackageApplier` searches it after
`/opt/unetlab/data/packages/trusted.d`, which is where an operator pins a
publisher of their own.

It is **empty**, and that is the honest state: the fork has no release signing
key yet. Creating one is a decision with custody consequences — where the secret
half lives, who can reach it, what happens when it is lost — and shipping a key
generated by a build script would be worse than shipping none, because it would
look like a trust root while being one anybody could reproduce.

Until a key exists here, updates and marketplace installs need a key pinned into
`/opt/unetlab/data/packages/trusted.d` by the operator. See `docs/PACKAGES.md`.

To create the fork's key:

    platform/packages/pnet-package keygen --out release --comment "pnetlab fork releases"

Commit `release.pub` here. Do not commit `release.key`, and do not keep it on a
machine that builds packages automatically.
