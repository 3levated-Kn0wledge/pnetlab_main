# Known-unfixed shell-injection sites. THIS LIST MUST ONLY EVER SHRINK.
#
# Every entry is a value that reaches a shell without escapeshellarg(), an
# intval()/floatval(), or an (int) cast, found by the tokenizer sweep in
# ShellEscapingTest.php. They are NOT exemptions and they are NOT safe. They are
# the sweep's honest starting position, recorded so that anything new fails the
# test while the pre-existing set stays visible instead of being papered over.
#
# The line-regex version of that test could not see a single one of these. It
# reported zero violations for its whole life because it inspected nothing.
#
# FORMAT
#   <path> <symbol>        one per line; blank lines and # lines are ignored.
#
# Identity is file plus symbol, deliberately not file plus line: line numbers
# churn under every unrelated edit. See sweep_report() in ShellEscapingTest.php.
# Current line numbers are printed by the test itself when an entry goes stale.
#
# TO REMOVE AN ENTRY
#   Escape the value at its source, run tools/run-tests.sh, and delete the line
#   the test reports as fixed. Bring SWEEP_BASELINE_MAX down with it.
#
# TO ADD ONE
#   Don't. A new entry is a new way for request data to reach a shell. If it is
#   genuinely unavoidable it belongs behind a `// sweep-exempt: <reason>` marker
#   at the call site, naming the value — not in here.
#
# WHAT IS LEFT, IN ONE SENTENCE
#   With one exception the whole of this file is now devices/ — the emulator
#   command lines built from template option strings and per-interface flags,
#   which are argument injection BY DESIGN and are a design decision the fork
#   still owes rather than a bug anyone can escape their way out of. Everything
#   that was a route from request data to a shell through an ordinary API
#   handler has gone.

# --- 6. Node and lab identity read back out of accessors ---
#
# getSession()/getPort()/getRunningPath() return properties loaded from the
# database. Not attacker-controlled on any path found so far, but not escaped
# either, and they are the values every emulator command is built around.
#
# Four of these are GONE and the reason is the same each time — the schema says
# the column is an int, so the code can say so too:
#   createRunningPath($lab_session, $node_session) now casts both. They are
#   lab_sessions.lab_session_id (AUTO_INCREMENT) and node_sessions.node_session_id
#   (allocated modulo 30000), both int(11), and the workspace path it builds is
#   interpolated into emulator command lines all over devices/.
#   $tpid[0] was a pid read back out of a previous exec() and handed to
#   `cgclassify -g pids:/cpulimit`; it is (int) now, in all three QEMU backends.
#   device_qemu_wp.php's $this->delay was the one raw value on a line that
#   escaped its other six.
#
# The three that remain are the ACCESSORS themselves, and they are left
# deliberately. Retiring them means `return (int) $this->session;` inside
# getSession(), which has 173 call sites and would turn a null session into 0 for
# every one of them — including six `== null` guards that read as "no session".
# That is a behaviour change to buy three lines in this file, and the values are
# int(11) columns either way.

includes/__node.php $this->port

# --- 7. Legacy API filesystem commands ---
#
# ALL GONE. api_folders.php ran
#     exec('rm -rf "' . BASE_LAB . $path . '" 2>&1')
# and the mv of $s to $d on folder paths taken straight off the request. The
# double quotes stopped word splitting and nothing else — $( ) and a backtick
# both expand inside them. Both are proc_open() with an argv array now, with
# `--` terminating option parsing; there is no shell left.
#
# What these entries were NOT is worth recording, because the obvious reading is
# wrong. They look like sites held up only by secureCmd()'s blocklist. They were
# not: checkFolder() in devices/functions.php is
#     preg_match('/^\/[\/A-Za-z0-9_\s-]*$/', $s)
# an allowlist applied to the whole path before the exec, stricter than anything
# in api_folders.php, and undocumented anywhere. Measured against the parent
# commit on the reference host: a folder named `x$(touch pnet_rce_proof)y` can be
# created, because apiAddFolder() validated nothing at all, and deleting it is
# then refused by checkFolder() with 60009 and nothing runs.
#
# The half that was genuinely open was apiAddFolder(), which is now validated
# too — so the three routes agree about what a folder name is, which they never
# did before.
#
# api_labs.php's $user['pod'] was the `rm -rf /tmp/import_<pod>` on the import
# route, and went the same way. The unzip beside it went with it, which also
# fixed a latent bug: its `*.unl` member pattern was unquoted, so the SHELL
# globbed it against the current directory and it reached unzip intact only
# because no .unl file was ever there.
#
# The $pid / $o[0] entries were values read back from a previous exec's output
# and fed to kill(1) without a cast. All three went earlier, with
# `unl_wrapper -a iol-keepalive`.

# --- 8. secureCmd() returns its input unescaped ---
#
# includes/functions.php `return $v;`, reported on the parameter it came from.
